# MainGameVrNeckChain

通常Hシーンの参加女性に、Augh の **Leash Choker** と **Chain Short Weighted** を呼び出します。

- 必要なmod: `F:\kks\mods\Koi Crap\[Augh] Chains v1.0.0.zipmod`
- 必要なmod: `F:\kks\mods\Koi Crap\[Augh] Leash Choker v1.0.2.zipmod`（同梱の首輪アイテムを使用）
- PlaybackBar の `ディルド` の隣にある `鎖` タブで表示・削除します。首輪は通常Hの最初の参加女性に装着され、鎖の根元は呼び出した瞬間から首輪のリングへ接続されます。
- デスクトップでは首輪・鎖の接続端・先端をそれぞれのギズモで保持して移動します。VRでは各部へ手を近づけてグリップで掴みます。鎖の両端は左右の手で同時に保持できます。
- 首輪を設定した距離以上引くと首から外れます。所定の位置へ近づけて離すと首に戻ります。首輪を外すと、接続済みの鎖も首輪と一緒に動きます。
- 鎖の接続端を首輪のリング近くで離すと、離した位置を首輪との相対座標で保存して接続します。`鎖の接続部分を外す` ボタンで接続端だけ外せます。
- 鎖の先端を離すと、接続中は元の DynamicBone へ戻ります。鎖の接続端も外れているときは鎖全体を重力で落とします。
- 首輪と鎖の接続端が両方外れ、すべての保持を離すと両方とも落下します。首から約1.5m下へ落ちた後は自動削除します。
- 首から届く長さを超えて手を動かすと、鎖は手の方向へ一直線に張り、先端は届く位置に留まります。女性の首は引っ張りません。
- 首輪の所定位置・回転・XYZ軸ごとの大きさ、首輪の着脱距離、鎖の接続位置とXYZ軸ごとの大きさ、掴み判定距離は `鎖` タブで調整できます。既存の全体倍率も残し、値は自動保存されます。
- 首から胴体までの簡易カプセルと、キャラに既存の胸用 DynamicBoneCollider がある場合はそれを使い、鎖が体へ埋まるのを抑えます。既存の胸用判定がない側には補助カプセルを置きます。床との衝突判定はありません。
- `鎖` タブの `コライダー表示` で、鎖専用の当たり判定を半透明で確認できます。青は補助、桃はキャラの既存の胸判定を鎖用にコピーしたものです。矢印で選択し、位置・回転のXYZ、半径倍率、長さ倍率を個別に調整できます。調整値は保存され、キャラ本体の判定は変更しません。

ゲームの起動・操作による実機確認は、このソースのビルドとDLL配置とは別に行ってください。
