# SBV2 JSON・CSV 一括音声化

`起動.bat` を開く。JSONまたはCSVを貼り付けるかファイルを選び、SBV2サーバーの「モデル取得」で接続を確認して「全件を音声化」を押す。保存先の初期表示は `F:\kks\BepInEx\plugins\canon_plugins\MainGameVoiceFaceEventBridge\ImpactCueAudio`。その直下に実在するフォルダがボタンで表示されるので、用途を選ぶ。フォルダ追加後は「更新」でボタンを再読み込みできる。任意の保存先パスも直接指定できる。再生用 `manifest.json` は `{"items":[{"file":"...wav","text":"..."}]}` 形式で書き出す。

接続先は「サブPC」（`http://192.168.11.30:5000`）と「メインPC」（`http://127.0.0.1:5000`）から選べる。選択後にそのサーバーのモデル一覧を取得する。メインPCが未起動なら、このアプリが `J:\ai_tools\voice\sbv2\app` のSBV2を自動起動する。各ローカルモデルの最新チェックポイントを使い、`c00_fera_chestfera_200` は200エポック最終版を選ぶ。サーバーURLを直接入力する場合は「手入力」を選び、「モデル取得」を押す。メインPCサーバーのログは `main_pc_server.log`。

直接保存すると新しい音声には用途名と日時入りの固有名を付けるため、既存のWAVを上書きしない。生成状況は画面に表示し、新たに作るファイルはWAVと再生用 `manifest.json` のみ。マニフェストには成功してWAVが存在する項目だけを入れる。成功が0件なら既存の再生用マニフェストは更新しない。画面で直接保存のチェックを外した場合は、保存先の下に `sbv2_batch_日時` フォルダーを作る。

入力例:

```json
["こんにちは", "おはよう"]
```

```json
[{"text":"こんにちは","intensity":50},{"moan":"こんばんは","intensity":80}]
```

```json
{"lines":["こんにちは","おはよう"]}
```

```csv
text,intensity
こんにちは,50
おはよう,80
```

`moan`、`セリフ`、`台詞`、`喘ぎ` 列も使える。別の列名でも、文字列列が1つなら自動判定する。複数候補があるときは画面の「CSV音声列」で指定する。見出しのない1列CSV、UTF-8のBOM付き、WindowsのShift-JIS（CP932）ファイルにも対応する。

`intensity` など音声テキスト以外の値は生成に使わない。接続先、モデル、保存先は画面で指定する。各件の成否は生成詳細JSONに残し、失敗があっても残りを続ける。停止時も生成済みWAVとZIPを保存する。

Python 3の標準ライブラリだけで動く。サブPCのSBV2は別途起動する。
