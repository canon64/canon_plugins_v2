# MainGameDisplacementMap

Full-screen displacement-map ripple effect for Koikatsu Sunshine / KKS VR.

Uses the proven capture + OverlayDrawer (OnPostRender) technique from SimpleAfterimage and MainGameCircularDisplacement, but drives the UV distortion from a procedurally generated low-res displacement texture (concentric waves + damping + noise).

Master `Enabled` toggle is at the top of the config.

See README_ja.md for details (Japanese).
