# MainGameRhythmSync

`MainGameBeatSyncSpeed` と `MainGameSpeedLimitBreak` の実処理を統合したプラグイン。旧名 DLL は互換ブリッジとなり、速度制御の本体はこの DLL に入る。

## 動作

- `MainGameBlankMapAdd` の追加マップで、動画再生時刻と曲の BPM を基準にする。
- 低音エネルギーが強い区間は 1 拍、中間は 2 拍、弱い区間は 4 拍でアニメーション 1 周期とする。
- H シーンの参加者を `lstFemale` / `male` / `male1` から取得し、一組の共通速度を全員に適用する。男女別の速度補正は行わない。
- BPM 補正は基準女性の進度から一回だけ計算する。音楽停止・一時停止・同期 OFF・再生情報の失効では全員の補正を解除し、手動速度へ戻す。
- 同じ状態の再生位置差が 0.001 周期を超えた場合は、相手自身の状態を基準女性の位置へ合わせる。時間ゼロの再評価中は AnimationEvent を抑止する。非ループ状態をゼロへ巻き戻さない。
- 体位切替中は共通速度を維持し、切替後に位置を合わせる。シーン終了・人物入替・プラグイン終了時は補正を解除する。
- 拍同期中は速度キューより拍同期を優先する。その他のキュー動作は実行する。
- `LeftAlt+S` で BPM UI を開くと「アニメーションを拍にリセット」ボタンがある。押した瞬間を拍の起点にする。
- 男女の同期は H シーン中常時有効。BPM 連動は追加マップでの動画再生中のみ有効。
- `pair v=0.2.0` ログに男女全員の ID・状態・速度・再生位置、速度差、位置差を同じ行に記録する。対応状態が異なる場合は `unmatchedStates` を警告として記録する。

## 移行

初回起動時、新しいファイルが無い場合だけ旧設定・曲別 BPM マップ・速度キュー JSON をコピーする。旧設定は上書きしない。
旧名の 2 DLL は、BlankMapAdd、カメラ、ライト、サブカメラ、音声効果、HandySync へ旧 API を提供するブリッジとして配布する。

## 制限

アニメーション 1 周期が腰の 1 往復であるモーションを対象にする。別の周期構成のモーションやトランジション中は実機での確認が必要。

## 検証

`dotnet run --project Tests/MainGameRhythmSync.Tests.csproj -c Release` で共通時計の収束、30/60/120fps、60/138/180BPM、1/2/4拍、停止・再開、処理落ちを検証する。
0.2.0 の実機起動・見た目の検証は、ユーザーの起動禁止指示に従い未実施。
