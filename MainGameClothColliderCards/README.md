# Cloth Collider Cards

KKS character cards store this plugin's collider definitions in KKAPI/ExtensibleSave data under `canon.kks.clothcollidercards`. The data contains each collider's character-relative bone path, sphere/capsule shape, local position and rotation, radius, capsule height, and capsule axis. On character reload the plugin recreates these colliders as children of the recorded bones.

In character maker, press **F6** to open the editor. Filter the bone list, select a bone, add a sphere or capsule, then select its row to edit position/rotation/size. Press **Apply values**, then save the character card. Reload the card to restore the definitions. Deleting a row and saving removes it from the card.

Run `python build_flare_zipmod.py` to install an independent maker entry **フレアスカートA（Cloth試作）** with source list ID `91025008`. It references the stock `p_o_bot_skirt05` prefab, while the original **フレアスカートA** (ID 8) stays unchanged. The editor window has **Flare skirt A Cloth Trial: enable cloth**. With the new entry selected, it clones the active skinned skirt renderers, pins the top 12% of the source mesh vertices by local Y, and gives the remainder a Unity `Cloth` travel distance that increases toward the hem (default 0.65 m). The source renderers are hidden while the clones are active. The card's colliders are assigned to the new Cloth components. The cloned item uses cloth by default; an explicit disabled setting in card data suppresses it. Clothing reloads and skirt visibility changes rebuild the clones; turning the setting off restores the source renderers and DynamicBone behaviours.

The existing MainGameBlankMapAdd HTTP server accepts live Cloth tuning. Read `GET http://127.0.0.1:<HttpPort>/cloth/status` and send JSON to `http://127.0.0.1:<HttpPort>/cloth/parameters`, for example `{"hemDistance":0.5,"damping":0.02,"gravity":true}`. Fields may be omitted; the request changes only supplied fields. `useTethers` toggles the cloth's anchor tethers; `worldVelocity` and `worldAcceleration` control how character movement and acceleration feed into the cloth (0–1). The response contains applied parameter values and `diagnostics`: read-back coefficient counts and distances, source and clone world dimensions, mean and maximum particle offset from the initial cloth state, particle motion per sample, root-bone motion per sample, and sample interval. Changes are applied to the running Cloth immediately and included in the character's ExtSave data when the card is subsequently saved. The port follows MainGameBlankMapAdd's `HttpPort` setting (currently 55982 in this installation).

`POST /cloth/reset` recreates the cloned Cloth at the current pose without changing saved parameters. Use it after selecting gravity settings when comparing motion from the same initial state.

The trial female card is `F:\kks\UserData\chara\female\KoikatsuSun_F_20261025221030562_布試験 フレア.png`. `python make_trial_card.py` rebuilds it from the existing 春野 千佳 card, sets the first outfit's bottom to the new item, and embeds three trial colliders plus the cloth switch. It also writes Sideloader's GUID and source slot marker so the item's runtime remapped ID can be resolved when the card is loaded. The test character retains the source card's appearance and thumbnail.

This is an experimental cloth conversion. Character transparency is not implemented. Only colliders created by this plugin are saved; pre-existing game colliders are left alone. Runtime cloth behavior and card load need in-game verification.
