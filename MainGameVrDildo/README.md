# VR バイブ

対象はゲーム標準のスタジオアイテム「バイブ」 (`studio/00.unity3d:p_koi_stu_vibe02_00`)。
フリーH中に PlaybackBar の「バイブ呼出」を押すと、元の色と形のまま8本のFK骨とウェイトを付けて生成する。
VRMOD（KKS_VR）は `KoikatsuSunshine.exe --vr` で起動する。掴み入力はVRMODの `VRGIN` コントローラーのGripを使用する。

## 操作

1. 初期状態では表示されない。フリーHで PlaybackBar の「バイブ呼出」を押すとカメラの約35 cm前に現れ、もう一度押すと削除される。設定で自動呼出も選べる。
2. VRコントローラーを下側の筒状の持ち手へ近づけ、グリップを押す。初期判定は持ち手中心から8 cm以内。
3. グリップを押し続ける間、持ち手が手に追従する。離すとその場に残る。
4. PlaybackBar の「テスト」を押して拡張パネルの「テスト」タブを開く。曲げ、入口・奥ターゲット、節ごとのコライダー、持ち手位置を調整し、「保存」を押す。

デスクトップでは「テスト」タブの「ギズモ表示」をONにする。ディルドに表示された軸をマウスでドラッグして移動・回転できる。タブ内の「移動」「回転」で操作を切り替える。ギズモをドラッグしている間は、初期設定の「VRで掴んだ時のみ」がONでも愛撫中の移動距離を計測する。VR中の操作は従来どおりグリップを使用する。

PlaybackBar が出ていない場合、`Ctrl+Shift+V` で呼出／削除、`Ctrl+Shift+B` でテストタブを開ける。タブを表示できない場面では従来の設定画面を開く。

自動追従がONのときは、先端から近い膣入口または口入口を選び、持ち手を動かさずに骨列を入口・奥の目標へ曲げる。口ターゲットは `cf_J_MouthLow` と `cf_J_FaceBase` を優先し、見つからない場合は頭に追従する仮の目標を作る。口の近くでは徐々に開口し、離れると元の口制御に戻る。設定画面で口の目標位置、開口距離・量・時間、口接触半径を調整できる。
自動追従を切ると各節のFK角度を手動で設定できる。設定は `VrDildoSettings.json` に保存される。
コライダーは膣側を選んで先端が膣入口に近づいたとき、女性キャラの膣用 DynamicBone に登録される。口側は位置から接触を判定し、膣用コライダー、愛撫ゲージ、強い声、腰反応には入力しない。
「節ごとの DynamicBoneCollider」で左右の矢印から節を選び、半径と長さを cm で指定できる。選択中はカプセルが黄色（無効な節は橙色）で表示され、「コライダー表示」がOFFでも編集中は見える。長さを指定すると骨の長さから独立した固定値になり、「長さを骨間の自動値に戻す」で従来の追従長へ戻る。

## 出し入れ反応の試作

愛撫中は剛体先端の移動距離を計測する。設定画面の「出し入れによる体の反応」は初期状態OFF。
ONにすると、ゆっくりした往復、高速の短い往復、深い一撃を判定し、HipHijackの腰IKと
有効な肩IKに移動量を加算する。深い一撃を優先し、押し出し方向はディルドの挿入方向から
左右20度以内（初期値）に制限する。既存の腰コントローラー操作には加算される。

愛撫中の右下速度ゲージは、移動距離ゲージとして使用する。減衰速度と満タン距離は
「バイブ設定」で調整できる。通常のHモードではゲーム標準の速度ゲージに戻る。
Composerでは回転オブジェクトを別の回転オブジェクトの子にし、子側の
「ゆっくり時だけ親を反映」をONにすると、ゆっくり中のみ親の軌道を設定ウエイトまで混ぜる。
親の影響が0の間は、子は親の軌道位置や接線角度に引きずられない。

## 確認範囲

ゲーム起動時に環境変数 `KKS_VRVIBE_SELFTEST=1` を渡すと、標準アイテムをロードし、
3節を各15度曲げた実際の `SkinnedMeshRenderer.BakeMesh` を検査してログに結果を残す。
この検査はVRグリップ操作やフリーH中の衝突結果を代行しない。
# 口接触中の音声

口への接触中は、対象女性のゲーム標準H音声と呼吸音、途中で発火する音声トリガーを抑えます。口形はゲームの「咥え」パターン 22 に切り替え、離れたら元へ戻します。専用のフェラ呼吸音を再生し、選択済みの台詞があれば設定した間隔で再生します。

口ターゲット設定では、接近中と咥え中の口形ID・開き度を個別に指定できます。初期値は接近中が口形21（舐め）で最大開き度0.6、咥え中が口形22（咥え）で開き度1.0です。先端と口入口の距離が12cmになると開き始め、2cmで接近中の最大開き度に達します。距離は補間され、「開き度の追従時間」で急な移動への追従速度を調節できます。

口音声の既定の読み込み先は `F:\kks\BepInEx\plugins\canon_plugins\MainGameVoiceFaceEventBridge\ImpactCueAudio\Oral\manifest.json` です。各項目は `file` と `text` だけでよく、WAVは同じ `Oral` フォルダに置きます。SBV2一括アプリで保存先「Oral」を選ぶとこの形式で更新できます。別の場所に置く場合は設定の「選択JSON」に絶対パスを入力し、「選択JSONと音声を再読込」を押します。従来の `clips` / `id` / `caption` 形式も読み込めます。JSONが無い間は選択台詞を鳴らさず、フェラ呼吸音だけを鳴らします。

選択台詞の再生開始時、同じJSONの `caption` を音声の長さだけ字幕表示します。追加マップでは既存の `MainGameSubtitleCore` に渡し、それ以外のHシーンや字幕プラグインが使えない場合はバイブ側の画面下部に表示します。呼吸音には字幕を付けません。

ゲームから抽出した初期の口音声と呼吸音は `python MainGameVrDildo\prepare_oral_audio.py` で `Oral` フォルダに再配置できます。このスクリプトは再生用 `manifest.json` を初期候補59本で上書きします。ゲームを起動する処理は含みません。
