# MainGameMilkSpray

## 粒子の分割数削減（1.3.5）

球体を周囲6分割・縦4分割に変更。1粒あたり本体20頂点・36三角形、
グロー込みで24頂点・38三角形（以前は90頂点・170三角形）。
近距離では輪郭・光沢の角張りが増える。改善量は同条件の計測ログで比較する。

## 処理時間の計測（1.3.3以降）

`06.負荷計測 / PerformanceLogEnabled` は初期値ON。更新DLLを読み込んだKKSで自動記録する。
保存先は配置先の `_logs/milk-performance.csv`。16MiBでローテーションし、現行＋過去2ファイルに制限する。
書き込み・文字列化は専用スレッドで行い、待ち行列が4096行に達したらゲームを止めず行を捨てる。
欠落数は `dropped_rows`。通常の `VerboseLog` やBepInExのディスクログ設定から独立している。

- `frame` 行: フレーム番号、観測点間の経過時間、ON/OFF、発動条件、停止状態、粒子・残像数、GC回数、処理時間。
- `camera` 行: カメラ名・ID、粒子数、頂点・三角形数、並べ替え・形状生成・メッシュ転送の所要時間。
- `late_ms` はLateUpdate全体。`detect_ms`（発射判定）、`init_ms`（初回描画初期化）、`simulation_ms`（粒子更新）、`fire_ms`（噴出予約）、`prepare_ms`（描画準備）などを含む。
- `ghost_update_ms` は `simulation_ms` の内数。`clear_ms` は条件外・OFF時などの全消去で、通常は `detect_ms` の内数。
- `camera_ms` は全カメラ呼び出しの合計で、`sort_ms`・`geometry_ms`・`upload_ms` を含む。camera行をframe行に足すと二重計上になる。
- 時間はCPU側の経過時間。GPUシェーダーの実行時間やGPU全体時間ではない。GC回数はゲーム全体の値。
- `frame_span_ms` は当該frameの観測開始から次frameの観測開始まで。他のプラグインや描画待ちも含む。`complete=0` はOFF切替・終了時の部分フレーム、`frame_gap!=1` は複数フレームの間隔なので平均から除外する。
- カメラが先に手動描画された場合も `Time.frameCount` で記録を分ける。frame行の頂点・三角形数は、そのフレーム内のカメラ呼び出しの最大値。

```powershell
python .\MainGameMilkSpray\analyze_performance.py --last-seconds 60
dotnet run --project .\MainGameMilkSpray\Tests\PerformanceTests.csproj -c Release
```

集計は最新セッションのフレーム全体／粒子あり／粒子なし／OFF、カメラ別、遅いフレームを表示する。
同じ場面の時間帯を比べ、MilkSprayの時間とフレーム全体の時間を分けて判断する。

## ビルドと配置

`canon_plugins` を作業ディレクトリとして実行する。

```powershell
.\MainGameMilkSpray\BuildShader.ps1
dotnet build .\MainGameMilkSpray\MainGameMilkSpray.csproj -c Release
```

シェーダーは Unity 2019.4.9f1 のバッチモードでビルドする。
生成した `Resources/milkliquid.bundle` は本体 DLL に埋め込まれる。
シェーダーを変更した場合は必ず先に `BuildShader.ps1` を実行する。
他プラグインの参照ビルドが出力した同名 DLL は使用しない。

ゲーム終了後、`bin/Release/net472/MainGameMilkSpray.dll` だけを
`F:\kks\BepInEx\plugins\canon_plugins\MainGameMilkSpray\` へコピーする。
配布先に外部シェーダーや追加カメラは不要。

## 進行方向に伸ばした球体と十字グロー（1.3.2）

- 球体を進行方向の前後に伸ばした楕円体として描画する。粒子ごとの直径×伸び率を全長とする。伸び率は 1～10 倍、未保存時の初期値は 3。1 倍なら球形。
- 非均一な拡大に合わせて法線を補正し、光沢と輪郭の透明化を計算する。
- 直径は既存の 0.5～20 mm。不要な旧設定は下記の起動時処理で削除する。
- 軸は速度方向に追従する。速度が 1 mm/秒未満の区間では、その直前の方向を解析的に求めて保持する。
- 残像は発生時の位置・軸・直径・全長を保存し、向きを変えずに縮小する。
- 不透明度は色のアルファと乗算。残像では濃さと時間減衰も乗算する。
- 境界の柔らかさは表面法線と視線から求め、色と光沢を一緒に減衰させる。0% は境界減衰なし。
- 発光・十字グローの強度は 0～10 倍、未保存時の初期値は 1。0 で両方 OFF。液体の色で自己発光し、周囲に縦横の柔らかな加算光を重ねる。残像・透明度の減衰も反映する。グローは本体と同じメッシュ・シェーダーで描画し、追加カメラや画面全体のぼかしは使用しない。
- 粒子と残像を一つのマテリアル・メッシュへまとめ、描画するカメラの奥行き順で並べる。形状・頂点・索引・並べ替えバッファを再利用する。
- 同時噴出 4 回、粒子 500 個、残像 3,000 個の上限、衣装条件、停止、OFF、シーン変更時の消去は継続する。

通常の設定は噴出時のスナップショットに保存する。最小・最大の逆転は保存値を変えずに読み替える。
ソース照合とビルド成功は、ゲーム内の外観や FPS の確認とは別に扱う。

シェーダー生成には `com.unity.modules.assetbundle` が必要。ビルド時のエラー・モジュール無効の警告を検出した場合は生成を失敗させる。

## ゲームの乳首アクセサリ取り付け点から放出（1.3.6）

`ChaControl.ChangeAccessoryParent` が乳首への取り付けに使う参照点 `a_n_nip_L/R` のワールド座標を、そのまま発射元にする。
毎回のLateUpdateでゲームの参照辞書を確認し、取り付け点が差し替わったときは放出履歴を消去する。
胸サイズ・姿勢による取り付け点の移動はゲーム側の変形を通して取得する。前後フレームの座標を放出時刻に補間する方式は維持する。
上下・左右角度は発射速度にのみ適用し、発射位置を移動しない。新たなメッシュ解析や装着済みアクセサリは不要。
以前の胸サイズ0/100のY/Z補正は使用を終了し、設定画面から隠す。保存値は復元可能な状態で保持する。
本体DLLのアクセサリ取り付け経路とのソース照合・Releaseビルドと、実機の発射位置確認は別に扱う。

## 乳首メッシュの変形への追従（1.3.7）

`a_n_nip_L/R` の親階層から同じボディの `cf_j_bnip02_L/R` を取得し、乳首先端付近の発射元に使う。標準ボディと UncensorBase の乳首先端付近の頂点は、この骨のローカル Z 約 0.673 mm にあり、骨へのウェイトは 100% だった。胸サイズ変更・姿勢変更で骨が動くたび、毎フレームそのワールド座標を取得する。
骨が見つからないボディは従来のアクセサリ取付点へ戻す。他の差し替えボディでの見た目の一致、およびゲーム内での位置一致は未確認。

## 発射元の補正を撤去（1.3.8）

発射元は `cf_j_bnip02_L/R` のワールド座標そのものを使用する。1.3.7 の 0.673 mm 固定補正と、旧胸サイズ別 Y/Z オフセット設定の読み込みを撤去した。角度設定は飛ぶ方向にのみ作用する。

起動時に `DropSize`、`TrailWidth`、`TrailLifetime`、`ForwardOffset`、`LengthMinMm`、`LengthMaxMm`、`JetCount`、`JetDiameterMm`、`BreakupDelayMs` と以前の左右個別X/Y/Z補正6項目を設定画面と保存ファイルから削除する。
粒子数・直径・伸び率・残像・発射タイミングなど、現在使用中の保存値は保持する。
